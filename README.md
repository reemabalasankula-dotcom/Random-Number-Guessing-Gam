
# Random Number Guessing Game Using C++

A C++ console-based game where the player tries to guess a randomly generated number between 1 and 100. The program provides hints after each guess, tracks the number of attempts, displays the final score, and allows the player to replay the game.

## Project Name
Random Number Guessing Game

## Features
- Random number generation between 1 and 100
- Hint messages ("Too High" or "Too Low")
- Attempt counter
- Score based on the number of attempts
- Replay option
- User-friendly console interface

## Software Used
- Code::Blocks IDE
- GNU GCC Compiler (MinGW)

## Language Used
- C++

## Concepts Used
- Random Number Generation (`rand()`)
- Random Seed (`srand(time(0))`)
- Conditional Statements (`if-else`)
- Loops (`do-while`)
- User Input and Output
- Attempt Tracking

## Header Files Used
- `<iostream>`
- `<cstdlib>`
- `<ctime>`

## How to Run
1. Open the project in Code::Blocks.
2. Open the `main.cpp` file.
3. Build and run the program.
4. Guess a number between 1 and 100.
5. Follow the hints until you guess the correct number.
6. Choose whether to play again.
